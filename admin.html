🔐 Administration

Collez votre code d'accès GitHub pour gérer les produits de la boutique.

Comment obtenir un code d'accès ?
  1. Connectez-vous sur github.com → créer un code.
  2. Repository access : choisissez Only select repositories puis site-longrich.
  3. Permissions → Contents : Read and write.
  4. Cliquez sur Generate token et copiez le code ici.
